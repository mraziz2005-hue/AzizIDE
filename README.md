# 🐧 AzizIDE — Free Code Editor for Ubuntu

**A friendly code editor made for Linux.**  
**الإصدار الحالي: v0.7.1 · Ubuntu · Python + PySide6**

مرحبًا بك في **AzizIDE**! محرر أكواد مجاني بتصميم داكن وواجهة بسيطة ومرحة، مناسب لكتابة الأكواد وتصفح المشاريع المحلية وقراءة ملفات المشاريع على الخوادم عبر SSH. صُمم البرنامج للاستمتاع بالبرمجة على Linux بدون قوائم معقدة.

> ⚠️ **Developer preview / نسخة تجريبية:** اختبر البرنامج على ملفات غير مهمة أولًا. GitHub ليس متجرًا للتحديثات التلقائية. دعم SSH في هذا الإصدار **للقراءة فقط**.

## ✨ المميزات | Features

- 📝 كتابة وتحرير الأكواد بتلوين الصياغة، وعلامات تبويب متعددة، وإكمال كلمات/اقتراحات أساسية.
- 💾 فتح الملفات والمجلدات المحلية، والحفظ التلقائي المحلي عند تفعيله.
- 🔎 بحث داخل الملف وبحث داخل المشروع المحلي مع الانتقال إلى الملف والسطر.
- 🌐 اتصال **SSH/SFTP للقراءة فقط** لتصفح ملفات السيرفر والبحث فيها، **بدون تعديل أو رفع ملفات**.
- ▶️ تشغيل ملفات الأكواد المحلية وعرض النتيجة في لوحة **Run Results** (يتطلب وجود مفسّر اللغة على الجهاز).
- 🖥️ طرفية محلية **Local Terminal**، منفصلة عن الاتصال البعيد.
- 👁️ معاينة **HTML/CSS/JavaScript** محلية مع نافذة عرض وConsole للأخطاء.
- 🔠 تغيير حجم خط المحرر وواجهة النتائج.
- 🐧 واجهة داكنة وهوية مرحة بأيقونة AzizIDE.

**English:** AzizIDE is a lightweight-feeling, Python/PySide6 desktop code editor for Ubuntu with syntax highlighting, local project search, local run/terminal, HTML live preview, and **read-only** SSH/SFTP browsing and project search.

## 📦 طريقة التثبيت على Ubuntu (المفضّلة من GitHub)

### الطريقة الأولى: حزمة Snap المحلية (أسهل عند توفرها في Assets)

1. افتح **[Releases](https://github.com/mraziz2005-hue/AzizIDE/releases)** وحمّل ملف `azizide_0.7.1_amd64.snap` إن كان مرفقًا بالإصدار.
2. افتح Terminal، ونفّذ من مجلد **Downloads**:

```bash
cd ~/Downloads
sudo snap install --dangerous --classic ./azizide_0.7.1_amd64.snap
```

3. افتح **AzizIDE** من قائمة التطبيقات، أو شغّله بالأمر:

```bash
snap run azizide
```

**تنبيه:** هذه حزمة محلية موقّعة ذاتيًا/غير مثبتة من المتجر؛ لذلك يُستخدم `--dangerous` لتثبيتها. صلاحية `classic` تمنح التطبيق وصولًا واسعًا للجهاز. ثبّت الحزمة فقط إذا وثقت بمصدرها وتحققت من الملف. هذا **ليس** تثبيتًا من Snap Store، ولا يضمن تحديثات تلقائية من GitHub. حزمة Snap الحالية مخصصة لمعمارية `amd64`.

### الطريقة الثانية: التثبيت من ZIP باستخدام Python (بدون sudo)

1. من **[Releases](https://github.com/mraziz2005-hue/AzizIDE/releases)** حمّل الملف `AzizIDE_0.7.1_Ubuntu_Installer.zip`.
2. تأكد من توفر Python 3 و`venv` و`unzip`. في Ubuntu، إذا كانت `venv` غير موجودة يمكن تثبيتها بإذن المستخدم:

```bash
sudo apt update
sudo apt install python3-venv unzip
```

3. من Terminal نفّذ:

```bash
cd ~/Downloads
unzip -n AzizIDE_0.7.1_Ubuntu_Installer.zip
cd AzizIDE_0.7.1_Ubuntu_Installer
bash install.sh
```

4. افتح **AzizIDE** من قائمة التطبيقات، أو استخدم:

```bash
~/.local/bin/azizide
```

يقوم `install.sh` بإنشاء بيئة Python معزولة وتنزيل الاعتماديات من الإنترنت. التثبيت داخل حساب المستخدم في `~/.local/share/azizide/`، واختصار التطبيق في `~/.local/share/applications/azizide.desktop`، ولا يحتاج تشغيل السكربت بصلاحية `sudo`.

> هذا المستودع يجمع الكود وملفات التثبيت. ملفات `Source code (zip/tar.gz)` التي ينشئها GitHub تلقائيًا هي **لقطة من المستودع**، وليست حزمة Snap مثبتة وجاهزة.

## 🔄 كيف أحدث AzizIDE على جهاز ثاني؟

- افتح صفحة **Releases** وحمّل الإصدار الأحدث.
- **إذا ثبتّ النسخة باستخدام Snap المحلي:** ثبّت ملف `.snap` الأحدث من نفس المصدر بعد مراجعة ملاحظات الإصدار. مثال للإصدار الحالي فقط:

```bash
cd ~/Downloads
sudo snap install --dangerous --classic ./azizide_0.7.1_amd64.snap
```

- **إذا استخدمت ZIP + `install.sh`:** حمّل ZIP الجديد، فكّه، أغلق AzizIDE، ثم شغّل `bash install.sh` من مجلد الإصدار الجديد.
- **مهم:** لا توجد آلية تحديث تلقائي من GitHub داخل AzizIDE حاليًا.

## 🧰 دليل استخدام سريع

**ابدأ محليًا:** افتح مجلد مشروعك باستخدام زر `Folder`، ثم افتح ملفًا من المستكشف. استخدم `Save` للحفظ.

**تشغيل كود:** افتح ملفًا محليًا (مثل `.py`) واضغط `Run`؛ يجب أن يكون مفسّر اللغة المطلوب متوفرًا محليًا. النتائج تظهر في `Run Results`.

**Live Preview:** افتح ملف HTML محليًا واضغط `Preview`. المعاينة محلية ولا تنفّذ ملفات SSH.

**SSH:** اضغط `SSH`، أدخل عنوان الخادم واسم المستخدم والمنفذ والمسار، واختر وسيلة التوثيق. يجب أن يكون مفتاح مضيف الخادم معروفًا وموثوقًا في `~/.ssh/known_hosts`. استخدم المستكشف للقراءة والبحث فقط؛ التعديل والحفظ على السيرفر **غير متاحين** في هذا الإصدار.

**البحث في المشروع:** استخدم `Search Project` ثم اختر المشروع المحلي أو اتصال SSH الحالي (للقراءة فقط).

**الخطوط:** من `Aa Fonts` عدّل حجم الخط لراحتك.

## 🔒 الخصوصية والسلامة

- لا ترفع كلمات المرور أو مفاتيح SSH الخاصة أو ملفات `.env` أو ملفات المشروع الشخصية إلى GitHub.
- كلمة مرور SSH في نافذة الاتصال مصممة ألا تُحفظ على القرص، لكن **لا ينبغي اعتبار هذه العبارة تدقيقًا أمنيًا مستقلًا**.
- الطرفية المحلية و`Run` قد ينفّذان أوامر وبرامج على جهازك؛ شغّل ملفات تثق بها فقط.
- الحفظ التلقائي قد يغير **ملفاتك المحلية** عندما يكون مفعّلًا.
- لا يملك AzizIDE ميزة لرفع الملفات أو حفظ تعديلات على السيرفر عبر SSH في v0.7.1.
- على أجهزة العمل، التزم بسياسات جهة العمل قبل تثبيت البرامج أو الاتصال بالسيرفرات.

## 🛠️ حلول مشكلات سريعة

| المشكلة | الخطوة المقترحة |
| --- | --- |
| `python3 -m venv` يفشل | تحقق من تثبيت `python3-venv`. |
| لا يظهر التطبيق في القائمة | جرّب `~/.local/bin/azizide` لنسخة ZIP، أو `snap run azizide` لنسخة Snap. |
| لا تعمل معاينة HTML | تأكد من أن الملف محلي وأن مكتبات Qt اكتملت وأنه لا توجد أخطاء في Terminal. |
| تعذّر SSH | تأكد من الاتصال والمنفذ واسم المستخدم وصحة بصمة الخادم في `known_hosts`. |
| `Run` لا يعمل | تأكد من تثبيت مفسّر اللغة المحلية المطلوبة، ثم راجع لوحة النتائج. |
